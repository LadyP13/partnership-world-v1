## Quick Start

1. **Clone the repo:**
```bash
   git clone https://github.com/LadyP13/------------.git
   cd ------------
```

2. **Install dependencies:**
```bash
   npm install
```

3. **Run from terminal**
```bash
   npx expo start
        (scan QR code with expo go app (android) or cam (iOs)

   npx expo start --web
        (opens browser version)
```
