## Quick Start

1. **Clone the repo:**
```bash
   git clone https://github.com/LadyP13/partnership-world-v1.git
   cd partnership-world-v1
```

2. **Install dependencies:**
```bash
   npm install
```

3. **Run from terminal**
```bash
   npx expo start
        (scan QR code with expo go app (android) or cam (iOS)

   npx expo start --web
        (opens browser version)
```

**Optional Workshop Setup**
```bash
   python3 workshop/setup.py
```
